# 🏠 Airbnb Clone - Full Stack Web Development Project

Welcome to my Airbnb Clone Project! 🚀

This is a major full-stack web development project that I built while learning from **Apna College**.

The project is inspired by Airbnb and focuses on building a real-world accommodation listing platform with frontend, backend, database, authentication, and CRUD functionality.

## 📌 Project Overview

The Airbnb Clone allows users to browse accommodation listings, view details, create listings, and manage their data through a full-stack web application.

The project is connected to **MongoDB Atlas** for cloud database management and deployed on **Render** for live hosting.

## 🏗️ Project Architecture

The project follows a full-stack architecture:

**Frontend → Express.js → Node.js → MongoDB Atlas**

The application is deployed on **Render** and uses **MongoDB Atlas** as the cloud database.
